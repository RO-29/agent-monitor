agent-monitor — setup & shortcuts

Approve permissions from this UI

Wire the MCP server once, and any Claude Code session launched with the right flag will route permission prompts here with Allow/Deny buttons.

Step 1. Add to ~/.claude/settings.json:

{
  "mcpServers": {
    "agent-monitor": {
      "command": "/Users/rohit/agent-monitor/agent-monitor",
      "args": ["mcp-perm-server"]
    }
  }
}

Step 2. Launch claude with the flag:

claude --permission-prompt-tool mcp__agent-monitor__permission_prompt

Notifications

Click the Notify button to toggle. When enabled you get an OS notification AND an in-page toast for any session that hits awaiting-permission. If only the toast shows, macOS is silencing OS notifications — fix in System Settings → Notifications → your browser → Allow Notifications, and turn off Focus / Do Not Disturb.

Tips

  • Click any tool-call chip inside a message to jump to that tool call.
  • Section headers collapse on click — your choices persist.
  • Light/Dark toggle (moon/sun icon) — persists in localStorage.
  • The session list is sorted by attention → state → recency.

CLI

Server runs under launchd at com.rohit.agent-monitor. Useful commands:

launchctl print gui/502/com.rohit.agent-monitor    # status
launchctl kickstart -k gui/502/com.rohit.agent-monitor  # restart
agent-monitor install-hooks   # patches ~/.claude/settings.json with hooks
agent-monitor mcp-perm-server # MCP stdio mode (Claude spawns this)
